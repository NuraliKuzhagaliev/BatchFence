## What changed

An exact identity checklist is derived from selected original documents and the case's recorded supplier/stock IDs, independently of both model stages. Negative and uncertain references count too. It is included in model input, and missing identities block document generation, source coverage, correction and subsequent intake. The checklist assigns no incident involvement or completeness. It is not a general recognizer of previously unknown IDs. The 40-candidate and bounded-input limits still reject oversized work rather than accepting a partial list. Existing explicit source-checked correction remains available; a corrected proposal is not relabelled as a successful raw model response.

The old RAG API result selected the right passage but returned `citations=[]`. The native-citation contract still rejects that result. Two diagnostic alternatives showed that native footnotes remained absent and copying the quote could omit its last safeguard. Neither was enabled as a fallback.

The explicit `indexed-source-selections-v1` contract instead requires a pinned isolated agent/library and independently read Evolus chunks. The server verifies membership, completed indexing, exact approved full passage text in an identified remote chunk, document/revision/source hashes, and retains chunk IDs plus body SHA256. Only then can a model-selected exact passage key resolve to the entire approved original. Foreign native annotations, unknown keys, missing proof, wrong versions, shortened indexed text and malformed output still fail closed. Citations are labelled **application-verified indexed sources**, not provider-native annotations or proof of which internal retrieval tool the provider used. The model is not asked to rewrite the displayed quote.

Existing indexed bindings can be explicitly reconciled to a verified agent without re-uploading or resetting ledgers. The old binding is not silently upgraded. New protocol bindings are enabled per reviewed isolated source set; the legacy global activation flag remains required for legacy/native-citation mode. Current free-allowance, private live-access, owner, role, stale-response, approval and release gates remain enforced.

Both clients gain an explicit RAG route and administrator reconciliation fields. Desktop generation transport permits 180 seconds so its former 55-second abort does not cut off the provider's existing 120-second RAG timeout. Other transport/security restrictions remain unchanged.
