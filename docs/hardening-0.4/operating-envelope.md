# Supported preview and controls

BatchFence0.4.0-rc.2 is a controlled engineering preview. All datasets and account reviews in this campaign are synthetic and agent-operated. Independent professional, language, physical-photo and unfamiliar-operator acceptance remain pending.

The supported containment model uses individually identified stock pools, integer pieces and cents, at most500 rows per stock/lineage/allocation dataset, explicit complete ancestry, directed acyclic lineage and confirmed/possible links. Shipped stock is exposure only; an unknown parent/incident boundary prevents unsupported exclusion. Recovery removes a reviewed whole-pool restriction reason, requires a distinct currently authorized approver, and becomes acknowledged only through its sandbox receipt or the explicitly configured reference connector. Other active incident reasons remain. Fractional, kilogram, arbitrary unit conversion and unidentifiable partial-pool releases are unsupported.

Original UTF-8/BOM TXT and CSV and bounded text PDF are supported. Duplicate/blank CSV headers, ragged rows, blank text, malformed numeric records and unsupported formats fail explicitly. PDF/OCR is isolated in a subprocess with bounded pages/time; a scan requires an available OCR engine and visual critical-field review. Parser/page/context limits never establish exhaustive incident scope. Mapped inventory, lineage, orders and inspections are separate review paths. New lineage entities require reviewed registration; the preview does not infer them. A valid unrelated-ID dataset can enter through the existing new-draft packet path; approvals and receipts are stripped, then source interpretation, critical review and exact approval are required again (sequence16,73 affected/41 outside).

PNG/JPEG/WebP label identity:2MB original,8million decoded pixels, single frame, bounded crop. Actual direct Gemma vision capability is separate from the text-only own-model Evolus catalog. A transcription is not authenticity, custody, quality or physical-photo validation. O/0 and multiple/uncertain readings prevent association. Exact identifier spelling and a separately reviewed source relationship are required.

Initial evidence languages EN/RU/IT; original values remain authoritative. Dates/decimals, missing IDs and changed modality are flagged. Derived translations cannot resolve scope or approve recovery. Unsupported languages require qualified assistance. Same-agent bilingual tests are not independent language validation.

Direct text requests:20KB payload,1600 maximum output tokens and48KB response bound; selected source context18,000 characters. JSON/schema/source occurrence and semantic uncertainty controls apply. The Evolus extractor/agent uses the verified own/gemma-4-31b-it connection; its execution API returns configured identity, not the underlying runtime model ID. No automatic model fallback, retry, inventory write, message or release.

Public Free Render: one instance, ephemeral SQLite/source storage, protected live-access token, scoped HttpOnly/Secure/SameSite cookie, server request/body/document limits, one live request at a time, persisted per-session/job limits while that database exists. Public anonymous Windows capability is intentionally memory-only; restarting requires a new workspace or historical packet. Private named-user pilot requires login and independently provisioned operational storage. No multi-tenant certification is claimed.

Provider enforcement is the cash boundary: the documented free AMD shared gateway hard daily account cap and Evolus event own-model zero price/no automatic renewal. App counters are additional throttles; they are not claimed to enforce a lifetime64-call allowance across a free-host reset. The private D-drive phase ledger preserves this engineering campaign separately from the completed48-call phase. Grant proof refresh does not change its identity, clear failures or reset counters. Verified provider proof is valid at most24h and never later than reset/event end; other proof remains subject to the original1h freshness gate. Unknown/expired proof blocks live dispatch, with no fixture substitution.

Export before restart, redeploy or proof expiry. Packets preserve original extracts, proposed versus applied quantities, raw proposals, reviews and receipts as read-only history; hashes detect changes and do not authenticate a supplier. Images need an authorized source-store backup as well. An isolated same-disk backup/restore and named Docker volume restart are engineering drills, not disaster recovery or Free Render durability. Owner RPO/RTO and off-device restore acceptance remain undefined.

Current dependency evidence: pinned Python requirements and production npm audit clear;8 moderate development-chain findings through electron-builder/@electron/get/global-agent/roarr/sprintf-js remain. Advisory suggests a toolchain downgrade; no blind force override was applied. Installer is unsigned. Current validated model performance does not support autonomous incident interpretation or release.
