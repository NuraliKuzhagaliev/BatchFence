# Risk register and architecture review

| Risk | Decision/control | Remaining acceptance |
|---|---|---|
| Incident-local stock permits unsafe recovery | Shared organization/site inventory and overlapping reason ledger; whole pools only | concurrent two-incident tests and domain policy review |
| Old anonymous approval becomes named | Preserve old hashes/receipts as historical; never migrate approval authority | migration regression |
| Smaller proposal mistaken for release | Persistent four separate quantity labels and separate receipt | unfamiliar operator comprehension |
| Missing proof or old procedure narrows/release | Explicit review, exact revision/action binding, source authenticity/check policy | domain owner policy approval |
| SQLite/PG divergence | Small parameter/transaction adapter; same suite on both | real PostgreSQL execution |
| Free cloud loses records | Public synthetic profile remains ephemeral; private local pilot profile + backup drill | owner off-device backup/RPO/RTO |
| Model/OCR sounds authoritative | Typed proposals, abstention, adjacent sources, explicit critical-field confirmation | frozen raw results and actual engine acceptance |
| All role tests operated by one agent | Disclose simulated/test actors; no independent validation claim | real distinct pilot identities and reviewers |
| Scope exceeds release gates | Separate branch, all modules tracked; keep verified 0.2.0 until new gates pass | incomplete functionality stays unpublished |
| Backup contains private sources/password hashes | Owner-only storage; no automatic cloud upload; secrets excluded, access documented | owner-controlled encrypted/off-device destination |

Architecture checkpoint: reuse FastAPI/React/Electron and canonical case snapshots. Add a minimal repository and scoped service functions; no managed queue, vector DB or new cloud service. Deterministic calculations own quantity/statistical decisions; models have no database/execution tools. No regulatory certification, real ERP action, production SLA or savings claim.
